# Fuentes y criterio del mapa muscular

Revisión: 20 de octubre de 2026. El mapa simplifica grupos musculares para visualizar ejercicios registrados. Las categorías principal/secundario son una decisión editorial de presentación; no representan una medición de activación, recuperación, ganancia muscular ni capacidad física.

## Regla del catálogo

`muscle_group` determina el grupo principal cuando identifica una región canónica concreta. Se normalizan mayúsculas, tildes y alias españoles. Un nombre de ejercicio no reemplaza una categoría concreta contradictoria. Para la categoría amplia `piernas`, solo se resuelven nombres reconocidos. Categorías desconocidas, cardio, cuerpo completo y aductores sin región SVG propia muestran «Mapa muscular no disponible».

Los alias se comparan completos; no se infiere una anatomía por una coincidencia parcial como `curl`, `press` o `remo`. No se añaden secundarios a todos los ejercicios de una región.
